Models & credits

Neo combines a native Mac window with small local models. The model files are downloaded from their publishers on Hugging Face during setup.

  • Qwen3 1.7B Q8_0 — Apache 2.0.
  • Qwen2.5-Coder 1.5B Instruct Q4_K_M — Apache 2.0.
  • SmolVLM 500M Instruct Q8_0 and vision projector — Apache 2.0.
  • llama.cpp — MIT.
  • Python — Python Software Foundation license and included third-party notices.
  • python-build-standalone — portable Python distribution.

Neo has not trained or fine-tuned these models. Licenses and attribution are included with the app. Neo is an independent project and is not affiliated with these model publishers.
