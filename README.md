# Neo Local AI

The official download website for Neo Local AI, an independent project by Omar Imran.

Website: https://neolocalai.isroot.in/

Static HTML, CSS and JavaScript hosted with GitHub Pages. This repository contains the public website and distributable app packages only. Each installed app runs the AI models on its own computer. Conversations and personal memory are never hosted here.

The current release is Neo Local AI 2.0.0: an early-access Apple silicon Mac app and a Windows x64 preview with a guided EXE installer. Both include saved conversations, Model hub, prompt plugins, local integrations, appearance settings and the opt-in local API. Qwen3.5 4B is an optional, checksum-verified 2.74 GB Model hub download. Media engines and weights are separate downloads. Obsidian memory is available on Mac only. Model and runtime attributions are listed in credits.html and included with the app. Packaging checks do not guarantee error-free operation on every computer.

All canonical URLs and the sitemap use the custom domain. Google chooses indexing and displayed results; this configuration does not guarantee a search ranking.
