# Neo Local AI

The official download website for Neo Local AI, an independent project by Omar Imran.

Website: https://neolocalai.isroot.in/

Static HTML, CSS and JavaScript hosted with GitHub Pages. This repository contains the public website and distributable app packages only. Each installed app runs the AI models on its own computer. Conversations and personal memory are never hosted here.

Mac 1.3 is an early-access Apple silicon release. Windows 1.3 is a preview and has not yet been tested on a Windows PC. Model and runtime attributions are listed in credits.html and included in each app download.

All canonical URLs and the sitemap use the custom domain. Google chooses indexing and displayed results; this configuration does not guarantee a search ranking.
